## 📖 專案簡介

Stonkfly 是一個以**真實果蠅全腦連接組（MaleCNS v1.0）**為基礎的神經模擬交易系統。系統將加密貨幣市場數據編碼為視覺影像，刺激果蠅的視網膜神經元，透過 166,000 個神經元的即時運算產生買賣決策，並以**纏論技術分析**作為學習目標，讓果蠅在模擬環境中學習交易。

### 核心概念

```
市場數據 → 視網膜編碼(320×180 RGB) → 果蠅大腦(166,000神經元) → 神經解碼 → 買賣決策
     ↑                                                                          ↓
     └────────────── 獎勵/懲罰(多巴胺) ←────────── 盈虧回饋 ←───────────────────┘
```

### 📉 三大交易引擎

#### 🦟 果蠅神經交易（主力）
- 果蠅神經網路參考纏論指標後自主決策買賣
- **買入條件**：果蠅說 BUY + 纏論說 BUY（共識），或纏論高信心(>70%)買入且果蠅不反對
- **賣出條件**：果蠅說 SELL + 纏論說 SELL（共識），或纏論高信心(>70%)賣出且果蠅不反對
- **最低持倉 15 分鐘**：避免短打，未到時間不能賣（TP3 止盈除外）
- **賣出後冷卻 15 分鐘**：避免追高
- **TP3 自動止盈**：價格達到均價+1.5%立即全數賣出（下跌趨勢+3%）
- **馬丁格爾加倉**：價格比均價低6%時加倉攤平，最多加倉2次（下跌趨勢禁止）
- **纏論賣出**：纏論指示 SELL 且超過最低持倉時間時全數出清

#### 🤖 無腦分型交易（輔助）
- 跟隨 5 分 K 線纏論分型訊號買賣
- 買入：底分型 + RSI 過濾 + 趨勢判斷
- 賣出：頂分型 + RSI ≥ 45 + 不虧損
- 5 分鐘交易後冷卻
- 與果蠅共用同一資金池

#### 🤖 分型多幣種機器人 [模擬]（獨立資金）
- **8 個幣種並行**：BTC、ETH、BNB、SOL、DOGE、WLD、ASTER、ZEC
- **獨立資金 $8,000**：每幣種 $1,000，與主交易帳戶分開計算
- 買入：底分型 + RSI 過濾 + 趨勢判斷（上漲 RSI<65、震盪<55、下跌<40）
- 賣出：頂分型 + RSI ≥ 45 + 最小利潤 0.3%
- 暖機機制：只交易啟動後新形成的分型
- 日式風格 UI 面板，迷你 K 線背景
- Telegram 通知開關（預設開啟）

### 支援 27 個交易對

|------|--------|
| **主流幣（10）** | BTC, ETH, BNB, SOL, ZEC, ADA, AVAX, DOT, LINK, LTC |

### 安裝

```bash
git clone https://github.com/fr303388/stonkfly.git
cd stonkfly
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -e .
```

### 啟動（三個進程）

```bash
# 1. 啟動監控伺服器
python monitor_pro.py

# 2. 啟動果蠅神經交易（主力）
python -m stonkfly.cli run --out runs/paper --products BTC-USDT --exchange binance --steps 1000 --hz432 --chan-auto

# 3. 啟動分型多幣種機器人
python -m stonkfly.fractal_multi_bot
```

監控位址：**http://127.0.0.1:8767**

### Telegram 設定（選擇性）

在 `.env` 檔案中設定：
```
TELEGRAM_ENABLED=true
TELEGRAM_BOT_TOKEN=你的BotToken
TELEGRAM_CHAT_ID=你的ChatID
TELEGRAM_NOTIFY_FRACTAL=true
```

設定步驟：
1. 在 Telegram 尋找 @BotFather 建立機器人，取得 Token
2. 尋找自己的機器人並發送一句話
3. 在 UI 設定面板輸入 Token 和 Chat ID

### 切換交易對

點右上角 ⚙️ 設定按鈕，選擇交易對和金額後按下切換。系統會自動清除舊資料並重啟所有進程。

## ❓ 常見問題

**Q: 為什麼 K 線圖沒有顯示？**
A: 確認幣安 API 可連線，Ctrl+Shift+R 強制刷新瀏覽器。

**Q: 怎麼切換交易對？**
A: 點右上角 ⚙️ 設定按鈕選擇交易對和金額，系統會自動重啟。

**Q: 神經模擬越來越慢？**
A: 系統內建每 25 步睡眠整理和記憶體回收，或手動重啟。

**Q: 為什麼交易頻率很低？**
A: 最低持倉 15 分鐘 + 賣出後冷卻 15 分鐘，避免短打。需要果蠅和纏論共識才會交易。

**Q: 分型機器人和主交易有什麼不同？**
A: 分型機器人使用獨立 $8,000 資金，同時監控 8 個幣種，與主交易帳戶完全分開。

**Q: 可以賺錢嗎？**
A: 這是研究專案，獲利能力未經驗證。
