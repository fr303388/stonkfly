## 📖 專案簡介

Stonkfly 是一個以**真實果蠅全腦連接組（MaleCNS v1.0）**為基礎的神經模擬交易系統。系統將加密貨幣市場數據編碼為視覺影像，刺激果蠅的視網膜神經元，透過 166,700 個神經元的即時運算產生買賣決策，並以**纏論技術分析**作為學習目標，讓果蠅在模擬環境中學習交易。

### 核心概念

```
市場數據 → 視網膜編碼(320×180 RGB) → 果蠅大腦(166,700神經元) → 神經解碼 → 買賣決策
     ↑                                                                          ↓
     └────────────── 獎勵/懲罰(多巴胺) ←────────── 盈虧回饋 ←───────────────────┘
```

#### 🦟 帳戶一：果蠅神經交易（初始資金 $100）

**核心邏輯**：果蠅大腦參考纏論指標，結合視覺價格百分位自主決策買賣。

**感光細胞輸入驅動的買賣規則**：
```
無持倉時（低點分批進場）：
  價格百分位 <= 20% → 買入
  價格百分位 <= 10% → 加倉
  價格越低，買得越多，攤低成本

有持倉時（高點全部賣出）：
  價格百分位 >= 90% → 全部賣出
  纏論說 SELL → 全部賣出
  都沒說 → HOLD觀察
```

**決策者標註**：
| 標註 | 條件 | 說明 |
|------|------|------|
| `[視覺觸底 第N批]` | 價格百分位低點 | 感光細胞檢測到低點，分批買入 |
| `[高點強制賣出]` | 價格百分位>=90% | 感光細胞檢測到高點，全部賣出 |
| `[果蠅+纏論]` | 雙方都說買/賣 | 共識決策，信心最高 |
| `[纏論參考]` | 只有纏論說 | 纏論技術分析訊號 |

**風控參數**：
- **止盈**：由高點檢測和纏論訊號判斷賣出時機
- **止損**：-3%自動賣出
- **初始資金**：100 USDT
- **手續費**：0（模擬環境）

**果蠅學習機制**：
- **獲利**：刺激 PAM11 獎勵神經元，強化正確決策的突觸連接
- **虧損**：刺激 PPL101 厭惡神經元，弱化錯誤決策的突觸連接
- **纏論學習**：冷卻期間自動學習纏論理論和實戰技能
- **進階學習**：21個概念分5個領域（纏論/指標/結構/風控/心理）

#### 🤖 帳戶二：無腦分型交易（初始資金 $100）

**核心邏輯**：基於 **1分K線** 纏論分型 + 價格百分位雙重觸發，反應快、提前進場。

**交易規則（三大改進）**：
```
無持倉時（買入條件任一觸發）：
  1. 價格百分位 < 20%（近100根K線最低20%）→ 提前買入一半倉位
  2. 出現底分型 + RSI < 55 → 全倉買入
  → 不再等分型完全確認，第2根反向K線就觸發

有持倉時（賣出條件任一觸發）：
  1. 價格百分位 > 80%（近100根K線最高20%）→ 提前賣出
  2. 出現頂分型 → 賣出
  3. 止損3% 或 止盈5% → 賣出
```

**三大改進（解決高買低賣）**：
| 改進 | 舊版 | 新版 |
|------|------|------|
| K線週期 | 5分/15分（延遲15-20分鐘） | **1分K線**（延遲1-2分鐘） |
| 分型確認 | 等3根K線確認 | **第2根就提前進場** |
| 價格百分位 | 無 | **<20%提前買 / >80%提前賣** |

**風控參數**：
- **K線週期**：1分鐘
- **初始資金**：100 USDT（獨立帳戶）
- **冷卻時間**：60秒（1分鐘）
- **止損**：3%
- **止盈**：5%
- **RSI門檻**：<55買入

## 📊 無腦交易改進說明（v2）

### 解決「高買低賣」問題

舊版無腦交易使用5分/15分K線，等分型完全確認需要15-20分鐘，等訊號出來時價格已經跑了一段。

**新版三項改進**：

1. **1分K線**：反應速度從15分鐘降到1分鐘
2. **提前觸發**：不等分型第3根確認，第2根反向K線就進場
3. **價格百分位**：
   - 近100根K線最低20%區間 → 自動買入（不等分型）
   - 近100根K線最高20%區間 → 自動賣出（不等頂分型）

這樣即使分型訊號延遲，百分位邏輯也能提前在低點買入、高點賣出。

## ❓ 常見問題

**Q: 為什麼 K 線圖沒有顯示？**
A: 確認幣安 API 可連線，Ctrl+Shift+R 強制刷新瀏覽器。

**Q: 怎麼切換交易對？**
A: 執行 `.venv\Scripts\python.exe start.py DOGE-USDT`，自動完成停止→切換→清數據→啟動。

**Q: 神經模擬越來越慢？**
A: 系統內建睡眠和記憶體回收，或重啟 start.py。

**Q: 無腦交易為什麼長時間沒動作？**
A: 新版使用1分K線+百分位，反應更快。若仍無動作代表市場在中間區間（百分位20-80%），等待趨勢到位。

**Q: 可以賺錢嗎？**
A: 這是研究專案，獲利能力未經驗證。
