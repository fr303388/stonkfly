## 📖 專案簡介

Stonkfly 是一個以**真實果蠅全腦連接組（MaleCNS v1.0）**為基礎的神經模擬交易系統。系統將加密貨幣市場數據編碼為視覺影像，刺激果蠅的視網膜神經元，透過 166,700 個神經元的即時運算產生買賣決策，並以**纏論技術分析**作為學習目標，讓果蠅在模擬環境中學習交易。

### 核心概念

```
市場數據 → 視網膜編碼(320×180 RGB) → 果蠅大腦(166,700神經元) → 神經解碼 → 買賣決策
     ↑                                                                          ↓
     └────────────── 獎勵/懲罰(多巴胺) ←────────── 盈虧回饋 ←───────────────────┘
```

## ✨ 功能特色

### 🧠 神經模擬
- **166,700 個真實果蠅神經元**，依 MaleCNS v1.0 連接組建構
- **2,560 萬突觸連接**，即時電化學傳遞模擬
- **3,335 個視網膜輸入神經元**，R1-R6 感光細胞層
- **多巴胺獎勵系統**：PAM11 獎勵細胞 + PPL101 厭惡細胞
- **432Hz 振盪刺激**：對 Kenyon 細胞施加療癒頻率
- **突觸可塑性**：候選記憶規則改變 KC-MBON 連接強度
- **學習記憶持久化**：brain-*.npz 檢查點 + chan_knowledge.json 自動保存

### 📊 纏論學習系統
- **理論學習器**：6 大核心概念（分型、筆、線段、中樞、背馳、買賣點）
- **實戰學習器**：6 項交易技能（突破回踩、背馳買賣、中樞震盪等）
- **知識持久化**：學習成果跨啟動保留
- **學習進度顯示**：理論/實戰/勝率/買點/賣點熟練度

### 📈 技術指標
- **RSI**：超賣區域輔助判斷買點
- **MACD**：DIF/DEA/柱狀圖，K線圖即時顯示
- **Bollinger Bands (20,2)**：K線圖即時顯示
- **EMA 12/26**：MACD 快慢線即時顯示在K線圖
- **趨勢過濾器**：EMA20/EMA60 自動判斷下跌/震盪/上漲趨勢
- **市場狀態偵測**：自動判斷震盪盤/趨勢盤

### 📉 交易策略（共用資金池）

#### 🦟 果蠅神經交易（主力）
- 果蠅神經網路參考纏論指標後自主決策買賣
- **TP3自動止盈**：價格達到均價+1.5%立即全數賣出
- **馬丁格爾加倉**：價格比均價低6%時加倉攤平，最多加倉2次
- **無止損**：馬丁格爾模式，靠加倉攤低成本等待反彈
- **纏論賣出**：纏論指示SELL時也會全數出清（雙重保險）
- **加倉後均價重算**：TP根據新加權均價重新計算

#### 🤖 無腦分型交易（輔助）
- 跟隨5分K線纏論分型訊號買賣
- 移動止盈：從持倉最高點回落1.5%賣出
- 與果蠅共用同一資金池，不獨立計算

#### 📊 趨勢過濾器（EMA20/EMA60）
| 趨勢 | 加倉 | 買入條件 | TP3止盈 |
|------|------|----------|---------|
| **下跌趨勢** | ❌ 禁止 | RSI<30超賣才考慮 | +3%（反彈就跑） |
| **震盪/上漲** | ✅ 6%加倉 | 纏論BUY訊號 | +1.5% |

### 🖥️ 即時監控介面
- **3D 神經元可視化（Swat真實電路）**：6,000個真實神經元
- **K 線圖**：TradingView Lightweight Charts，支援 1m/5m/15m

- **🎮 果蠅小遊戲**：滑鼠引導果蠅、放置食物、蒼蠅拍模式

### 安裝

```bash
git clone https://github.com/fr303388/stonkfly.git
cd stonkfly
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -e .
```

### 啟動

```bash
# 1. 啟動監控
python monitor_pro.py

# 2. 啟動交易
python -m stonkfly.cli run --out runs/paper --products BNB-USDT --exchange binance --steps 1000 --hz432 --chan-auto
```

監控位址：**http://127.0.0.1:8767**

### 切換交易對

點右上角 ⚙️ 設定按鈕，選擇交易對和金額後按下切換。
